# Documentación

Esta carpeta centraliza la documentación técnica del proyecto.

## Estructura

- **`decisions/`** — *Architecture Decision Records* (ADR). Cada decisión
  técnica importante se registra como un documento numerado e inmutable, para
  conservar el **porqué** de cada elección, no solo el resultado.

A medida que el proyecto crezca, aquí se añadirán:

- `architecture/` — diagramas y descripción de la arquitectura del sistema.
- `guides/` — guías de desarrollo (cómo levantar el proyecto, contribuir, etc.).
- `api/` — documentación de la API.
